This storefront is a visual and catalog transformation of the existing ecommerce engine (Next.js App Router, TypeScript, Tailwind CSS). There is no backend and no live payment processing.

## Tech Stack

- **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Radix UI** primitives
- **Framer Motion**
- **Embla Carousel**
- **React Context** (cart, wishlist, recently viewed)
- **localStorage** persistence

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run start
```
